# Analisis de Datos DF Titanic
Este repositorio contiene un ejercicio realizado con los datos de los pasajeros del Titanic, en donde se buscan los príncipales factores de supervivencia.

Se realizó un primer acercamiento a los datos para luego continuar con las visualizaciones, de las cuales se hallan insights.

## Librerías usadas:
- Pandas
- Numpy
- Matplotlib
- Seaborn
